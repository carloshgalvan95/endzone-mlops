# Notebooks

Exploration only. Product code lives in `endzone/`.

Name a notebook `N.N-initials-description.ipynb`.

- `N.N` is a two-level number, for example `1.0` or `2.1`.
- `initials` are the author initials, for example `cg`.
- `description` is a short kebab-case topic.

Example: `1.0-cg-pregame-eda.ipynb`.

Notebook files stay gitignored. This README is the tracked naming convention.
